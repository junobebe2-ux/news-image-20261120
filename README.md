# THE WORLD — Friday 20 November 2026

A program that writes one image summing up Friday 20 November 2026's world news — a newspaper front page called THE WORLD — to `/output/entry.png`. The front page carries the day's biggest stories: the AI race, the markets, the climate talks, the space launch, and the football, laid out as a broadsheet a picture editor would recognise at a glance.

Built for the [make.fun bounty news-image-20261120](https://make.fun/bounty/news-image-20261120).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That renders the front page and writes `out/entry.png` (1800×1200).
